Get Fiscal running and set up your first budget in about five minutes.

## Install

Fiscal requires [Node.js](https://nodejs.org/) 20 or newer.

```bash
npm install -g fscl
```

You can also skip the install and run `npx fscl init` directly. The setup wizard offers to install fscl globally when it finishes.

## Create your first budget

Run the init wizard to create a budget and write your config:

```bash
fscl init
```

You'll be asked to choose a mode:

- **local** creates a budget on your machine. No server needed. Pick this if you're just getting started or don't plan to use the Actual Budget web UI.
- **remote** pulls down a budget that already exists on an [Actual Budget server](https://actualbudget.org/docs/installing/). Pick this if you're already using Actual Budget and want to manage it from the CLI.

If you start local and later want to sync to a server, run `fscl budgets push`.

When the wizard finishes, check that everything works:

```bash
fscl status
```

This shows your budget, accounts, and server connection if you have one.

## Install the agent skills

Fiscal includes a set of [Agent Skills](https://agentskills.io/) that teach your AI agent to act as your personal accountant. The skills cover budgeting, bank imports, and transaction categorization, so you don't have to memorize any commands.

In interactive mode, `fscl init` asks whether to install these skills for you. If you skipped that step, or ran `fscl init --non-interactive`, install them yourself:

```bash
npx skills add fiscal-sh/fscl
```

This works with Claude Code, Cursor, Codex, and [other agents that support skills](https://github.com/vercel-labs/skills#supported-agents). To update the skills later, run the same command again. It pulls the latest version from GitHub.

## Start using it

With the skill installed, just talk to your agent in plain language:

> Help me set up my budget with fscl.

The agent will ask about your bank accounts, income, and spending categories, then create everything using fscl commands behind the scenes. You don't need to know the CLI. Just answer its questions.

### Day-to-day tasks

Once your budget exists, hand off routine work to your agent:

**Import a bank statement:**

> Import ~/Downloads/january-checking.ofx into my checking account and categorize everything.

The agent will import the file, run your rules to auto-categorize known payees, and ask you about anything it doesn't recognize. It creates rules as it goes so future imports get smarter.

**Check your budget:**

> How am I doing this month?

**Set up next month:**

> Set up my budget for March. Same as last month but bump groceries to $600.
